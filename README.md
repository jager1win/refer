# Refer - reference designer

Android Storage Permission

This app requires "All files access" permission to work with Documents/refer folder.

Enable it manually:

    Settings → Apps → refer → Permissions → All permissions

    Special access → All files access → Enable


Для главного экрана (короткая фраза)

    Enable "All files access" in Android Settings → Special access

Или ещё короче:

    Grant "All files access" permission in Android settings

Или максимально коротко:

    Enable all files access → Settings

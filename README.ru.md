### Refer - конструктор пользовательских справочников.

- - -

Основное предназначение - быстрый локальный инструмент для человека, которому нужно не просто хранить данные, а считать их на лету «в полевых условиях» без интернета.

- - -

### Ключевая особенность — Операции
Добавляются по желанию. Превращают справочник в инженерно-расчётный.

Создаётся формула с переменными, которые могут быть:
- полями типа `number` из самого справочника,
- значениями, вводимыми вручную,
- и тем и другим одновременно.

Каждая Операция привязывается ко всем элементам справочника.

Реализовано с помощью крейта [exmex](https://github.com/bertiqwerty/exmex) — синтаксис переменных, операторов и констант см. в документации крейта.

- - -

### Версии
Android, Linux, Windows — все сборки на Github.

### Языки
13 языков. EN и RU — вручную, остальные сгенерированы LLM: ES, FR, DE, PT, ZH, JA, KO, IT, NL, TR, AR.

- - -

### Встроенные справочники
6 примеров с операциями. Можно ломать, редактировать. Пересоздаются из меню «Создать» одним кликом.

- **Shrinkflation** — сравнение цен за единицу веса/объёма
- **Dilution** — коэффициенты смешивания растворов
- **Ballistics** — баллистический калькулятор
- **Deposit** — рост сложных процентов
- **Geometry** — окружность и сфера, введите радиус
- **Oscillator** — значение волны в момент времени t — используйте подсказку по времени в качестве ориентира

- - -

### Хранение
Директория `~/Документы/refer`, расширение `.refer`. По факту — базы SQLite. Можно создать на одном устройстве, перекинуть на другое.

Поддерживаются подпапки — встроенные примеры создаются в `refer/example`.

Приложение работает только с этой папкой и не использует интернет.

- - -

### Импорт
Справочник можно создать с нуля или импортировать:

- **CSV, TSV** — предпочтительна кодировка UTF-8
- **XLS, XLSX, ODT** — импортируется первый лист. Не рекомендуется для очень больших файлов: медленный импорт, большой размер
- **SQLite** — импортируется первая таблица

- - -

### Принципы

**Простота.** Аналоги перегружены функционалом. Refer работает с конкретным элементом, полный список не выводится — поиск выдаёт максимум 10 элементов.

**Минимум ограничений.** Возможны ошибки — логи в меню «Настройки» или по пути на главном экране.

**Безопасность.** Шифрование не добавлено намеренно — используйте средства ОС.

- - -

### ⚠ Предупреждение для Android
Требуется разрешение «Доступ ко всем файлам» для работы с папкой «Документы/refer».

Включить вручную (зависит от телефона):
- Настройки → Приложения → Refer → Разрешения → Все разрешения
- Специальный доступ → Доступ ко всем файлам → Включить

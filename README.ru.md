### Refer - конструктор пользовательских справочников. 
- - -
Основное предназначение - быстрый локальный инструмент для человека, которому нужно не просто хранить данные, а считать их на лету «в полевых условиях» без интернета.

Ключевая особенность приложения - ***Операции*** (добавляются по желанию) - которая может сделать ваш справочник инженерно-расчетным.  
Создается формула с переменными, которые могут быть как полями типа "number" из самого справочника, так и вводимыми вручную значениями.  
Каждая Операция привязывается ко всем элементам справочника.
Реализовано с помощью крейта exmex(внизу есть ссылка для ознакомления с синтаксисом переменных, операторов и констант)

На Github есть версии приложения для Android, Linux, Windows.

Мультиязычное, 13 языков (кроме первых двух файлы переводов сгенерированы с помощью llm): EN, RU, ES, FR, DE, PT, ZH, JA, KO, IT, NL, TR, AR.

В приложение встроено 6 справочников для примера со встроенными операциями:
- **Shrinkflation** - Сравните цены за единицу веса/объема
- **Dilution** - Рассчитайте коэффициенты смешивания растворов
- **Ballistics** - Калькулятор баллистической траектории для винтовочных калибров
- **Deposit** - Рассчитайте рост сложных процентов
- **Geometry** - Размеры окружности и сферы — введите радиус
- **Oscillator** - Значение волны в момент времени t — используйте подсказку по времени в качестве ориентира
Можно как угодно попрактироваться в них - они пересоздаются из меню "Создать" одним кликом.

Справочники на всех ОС хранятся в диретории ~Документы/refer и имеют такое же расширение - *.refer и по факту являются базами SQLite с определенной структурой. То есть можно создать на одном устройстве и затем перекинуть готовый справочник на другое устройство. Поддерживаются подпапки - например встроенные примеры создаются в папке refer/example. Приложение на всех ОС работает только с этой папкой и вложенными в нее и не использует интернет в принципе.

Можно создать справочник полностью с нуля или импортировать из распространенных форматов:
- CSV, TSV. Предпочтительна кодировка UTF-8.
- Таблицы (XLS, XLSX, ODT). Импортируется первый лист. Не рекомендуется для больших файлов: процесс может быть медленным, а итоговый размер справочника — большим
- Другие базы SQLite. Импортируется первая таблица

Одной из целей при создании приложения было минимум ограничений для пользователя. Поэтому вы наверняка столкнетесь с ошибками - их можно посмотреть в меню "Настройки" или в отображаемом на главном экране пути к файлу логов.

Безопасность: намеренно не добавлял кому-то может и нужное шифрование, но это можно сделать средствами любой ОС.

⚠ Предупреждение для Android:
- - -
Для работы с папкой «Документы/refer» этому приложению требуется разрешение «Доступ ко всем файлам».
Включить его вручную(зависит от вашего телефона):
- Настройки → Приложения → Refer → Разрешения → Все разрешения
- Специальный доступ → Доступ ко всем файлам → Включить
